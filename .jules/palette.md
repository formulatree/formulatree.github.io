## 2026-07-17 - Keyboard Event Duplication on Custom vs. Native Controls
**Learning:** When using a global keydown listener to add Enter and Space keyboard support for custom interactive elements (e.g., `role="button"`, `role="option"`, or `role="tab"` assigned to `div`s and `span`s), native interactive elements such as `<button>`, `<input>`, `<select>`, and `<textarea>` must be ignored in the listener logic. If not ignored, programmatic `.click()` invocations on these elements cause duplicate click event firings because browsers already natively translate Enter and Space into clicks for native interactive controls.
**Action:** Always filter out native input/action elements (`target.tagName !== 'BUTTON'`, etc.) in centralized keydown listeners before triggering click behavior.

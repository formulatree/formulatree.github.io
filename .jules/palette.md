## 2026-07-18 - Platform-Specific Accessibility and Focus Management in Static Hybrid Web Apps
**Learning:** Dynamic, platform-specific shortcut hint updating (e.g., changing '⌘K' to 'Ctrl+K' and suffixing aria-labels) on DOMContentLoaded ensures screen reader and visual parity across varying operating systems. Furthermore, using a centralized keydown event listener in shared data/utility files targeting elements with custom interactive roles ('button', 'option', 'tab', or tabindex) provides extensive keyboard navigation support with minimal code overhead, provided native interactive elements are excluded to prevent duplicate click handlers.
**Action:** Always identify interactive custom div/span structures, assign them explicit keyboard roles and tabindexes, style focus indicators cleanly with ':focus-visible', and register a centralized helper event listener excluding native interactive components.

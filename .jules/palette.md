## 2026-08-01 - Platform-Aware Search Accessibility
**Learning:** Adding dynamic platform-aware shortcuts like `⌘K` or `Ctrl+K` using visual `<kbd>` tags can cause screen readers to announce confusing fragments (e.g. "command key" or "control key") inside interactive search buttons, or read duplicate text. Standardizing search button labels with a clean base text, marking visual decoration (like icons and `<kbd>` hints) with `aria-hidden="true"`, and defining a complete, accessible `aria-label` that includes the platform-specific shortcut provides a seamless screen reader experience.
**Action:** Always wrap visual shortcut indicators and icons in `aria-hidden="true"` and apply a unified, platform-aware `aria-label` to the parent button instead of letting screen readers parse the mixed visual content directly.

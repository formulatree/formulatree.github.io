## 2026-05-16 - Global Keyboard Accessibility for Custom Elements
**Learning:** Centralizing keyboard event handling (Enter/Space) in a shared utility file like `data.js` is an efficient way to provide accessibility to custom interactive elements (with roles like button, tab, or option) across a multi-page static site, avoiding logic duplication and ensuring consistent behavior.
**Action:** Use shared JavaScript files to implement global listeners for ARIA-compliant keyboard interactions in multi-page static applications.

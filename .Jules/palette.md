## 2025-05-14 - Accessibility & Keyboard Polish
**Learning:** The FormulaTree app uses many custom interactive elements (divs as search results, formula headers as buttons) without proper ARIA roles or keyboard support. Additionally, the dark theme lacks visible focus indicators.
**Action:** Implement a comprehensive accessibility pass including :focus-visible styles, platform-aware shortcut hints, and ARIA role/attribute management across all pages.
